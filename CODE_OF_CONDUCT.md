# Código de conducta

El Open Lab busca sostener espacios accesibles, horizontales y respetuosos.

Esperamos que quienes participen:

- Traten a las demás personas con respeto, sin importar experiencia, profesión, identidad o nivel técnico.
- Acepten preguntas básicas y desacuerdos de buena fe.
- Den crédito a quienes aportan ideas, código, datos o documentación.
- Eviten publicar información personal o material que no tengan autorización para compartir.

No se tolerarán acoso, discriminación, amenazas, exposición de datos personales ni uso deliberado del espacio para dañar a otras personas.

Para reportar una situación, abrí un Issue privado o contactá al equipo responsable de la organización institucional.
