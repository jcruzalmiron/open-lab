# Política de licenciamiento propuesta

Esta es una propuesta para ratificar con la Fundación antes de publicar.

## Código

Apache-2.0 como licencia por defecto para código reutilizable, salvo que un proyecto tenga una razón documentada para usar otra licencia compatible.

## Documentación y materiales educativos

Creative Commons, preferentemente CC BY 4.0 o una variante que la Fundación apruebe.

## Datasets

Cada dataset debe conservar la licencia y las condiciones de la fuente original. Si no se puede documentar la procedencia o la autorización de publicación, no se incorpora.

## Regla práctica

La licencia debe aparecer en el repositorio y en el README. No se debe copiar material externo solo porque sea accesible en internet.
