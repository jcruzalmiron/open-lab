# Open Lab

Catálogo público de proyectos de la Fundación para la Democratización de la Inteligencia Artificial.

Open Lab funciona como portada: ayuda a entender qué proyectos existen, en qué estado están y cómo participar. El código y la documentación completa viven en repositorios independientes.

## Cómo proponer un proyecto

1. Abrí una Discussion con el problema, la comunidad destinataria y el resultado esperado.
2. Buscá personas interesadas y una persona responsable de coordinación.
3. Pasá la propuesta a un Issue cuando haya un primer alcance concreto.
4. Creá el repositorio desde `project-template` cuando el proyecto esté listo para comenzar.
