# Checklist de validación

- [ ] El territorio está acotado.
- [ ] Cada observación tiene fecha y procedencia.
- [ ] Se diferencian testimonios, observaciones, datos abiertos y fuentes oficiales.
- [ ] La prioridad tiene un criterio explicable.
- [ ] Los casos ambiguos no se presentan como hechos confirmados.
- [ ] No se publican domicilios ni datos personales.
- [ ] El mapa o croquis no se presenta como alerta oficial.
- [ ] Se documentan fuentes, prompts, decisiones y limitaciones.
