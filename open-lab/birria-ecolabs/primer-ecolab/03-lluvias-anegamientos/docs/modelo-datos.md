# Modelo de datos inicial

El primer taller debe trabajar con datos ficticios o anonimizados. Este esquema sirve para discutir el producto sin prometer una cobertura real de Rosario.

```text
observacion_id
zona_referencia
fecha_observacion
situacion_observada
fuente_tipo
frecuencia_percibida
impacto_observado
prioridad
accion_posible
validacion_pendiente
```

## Fuentes permitidas para el prototipo

- observaciones producidas durante la actividad;
- datos públicos con licencia y fecha identificables;
- ejemplos sintéticos creados para probar el flujo.

## Fuentes que requieren autorización o revisión

- datos de organismos públicos no destinados a redistribución;
- información de personas o viviendas identificables;
- datos de emergencias, salud o vulnerabilidad;
- mapas con precisión que pueda exponer a una persona.
