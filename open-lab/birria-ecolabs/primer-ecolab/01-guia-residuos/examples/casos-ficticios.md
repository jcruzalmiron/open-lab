# Casos ficticios para probar la guía

Usar estos casos solamente como ejemplos de taller. No representan una guía oficial de Rosario.

- Una botella de plástico limpia.
- Restos de frutas y verduras.
- Una caja de cartón húmeda.
- Un envase con restos de pintura.
- Una yerba usada.
- Un aparato electrónico que dejó de funcionar.

El grupo debe marcar cuáles pueden resolverse con una regla general y cuáles requieren consultar una fuente local o especializada.
