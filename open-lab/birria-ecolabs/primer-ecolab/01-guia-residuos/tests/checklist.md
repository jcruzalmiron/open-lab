# Checklist de validación

- [ ] La guía se entiende sin explicación oral.
- [ ] Cada recomendación distingue certeza de supuesto.
- [ ] No aparecen direcciones ni puntos de recepción inventados.
- [ ] Los casos ambiguos quedan marcados.
- [ ] Los mensajes invitan a una acción concreta.
- [ ] No se incluyeron datos personales.
