# Kit de demo

Para el taller se puede usar un caso ficticio: una escuela quiere reducir residuos orgánicos y explicar el compostaje a las familias.

El grupo debe producir:

1. un cartel para colocar en la escuela;
2. un mensaje breve para las familias;
3. una publicación para redes;
4. una pregunta de validación para docentes y familias.

No presentar el caso como una campaña real ni utilizar nombres de instituciones sin autorización.
