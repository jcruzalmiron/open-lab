# Checklist de validación

- [ ] La acción esperada aparece explícita.
- [ ] El público puede entender el mensaje sin contexto adicional.
- [ ] Se evitó el tono culpabilizante o alarmista.
- [ ] Las variantes mantienen el mismo sentido.
- [ ] La pieza tiene una fuente o una pregunta de verificación.
- [ ] Se revisó accesibilidad, legibilidad y lenguaje claro.
- [ ] No hay datos personales ni logos sin autorización.
