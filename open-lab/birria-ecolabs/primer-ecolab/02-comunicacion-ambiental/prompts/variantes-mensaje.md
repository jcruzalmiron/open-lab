# Prompt para variantes de mensaje

```text
Ayudame a crear una campaña comunitaria sobre [PROBLEMA].

Público: [PÚBLICO].
Contexto: [CONTEXTO].
Acción concreta que queremos facilitar: [ACCIÓN].
Fuente disponible: [FUENTE O PENDIENTE].

Proponé un mensaje para mensajería, uno para cartel y uno para redes.
Usá lenguaje claro, inclusivo y no alarmista. No inventes datos locales.
Marcá toda afirmación que requiera validación. Explicá qué podría malinterpretarse.
```
