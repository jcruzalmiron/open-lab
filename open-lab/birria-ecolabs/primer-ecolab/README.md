# Primer EcoLab

## Tres proyectos iniciales para clonar, explorar y continuar

Este es el punto de entrada práctico de BIRRIA EcoLabs. Reúne tres proyectos con distintos niveles de complejidad para trabajar en el encuentro y continuar después en el Open Lab.

## Acceso rápido

Escaneá el QR para abrir esta carpeta directamente en GitHub:

![QR del primer EcoLab](assets/qr-primer-ecolab.png)

Enlace directo: <https://github.com/jcruzalmiron/open-lab/tree/main/open-lab/birria-ecolabs/primer-ecolab>

## Clonar el hub completo

```bash
git clone https://github.com/jcruzalmiron/open-lab.git
cd open-lab/open-lab/birria-ecolabs/primer-ecolab
```

Después, elegí un proyecto:

```text
01-guia-residuos/
02-comunicacion-ambiental/
03-lluvias-anegamientos/
```

Cada carpeta tiene su propio README, documentación de alcance, prompts seguros, ejemplos y criterios de validación.

## Los tres proyectos

### 01 - Guía de residuos y compostaje

Nivel inicial. Ayuda a convertir dudas cotidianas en una guía simple de separación, reducción, reutilización y compostaje.

[Abrir proyecto](01-guia-residuos/)

### 02 - Comunicación ambiental comunitaria

Nivel medio. Convierte un problema o hallazgo ambiental en una campaña clara, inclusiva y adaptable a distintos públicos y canales.

[Abrir proyecto](02-comunicacion-ambiental/)

### 03 - Lluvias intensas y anegamientos

Nivel alto. Organiza observaciones territoriales, explicita incertidumbres y prepara una matriz de riesgos y un prototipo de mapa comunitario.

[Abrir proyecto](03-lluvias-anegamientos/)

## Estado del hub

En esta primera etapa los tres proyectos viven dentro del repositorio público `jcruzalmiron/open-lab`. Cuando uno alcance suficiente madurez, puede extraerse a un repositorio propio desde `project-template/`, conservando su documentación y trazabilidad.

## Regla de publicación

No subir datos personales, domicilios, teléfonos, credenciales, datasets sensibles ni afirmaciones locales sin fuente. Los prototipos de EcoLabs no son sistemas oficiales de alerta ni reemplazan la validación de organismos competentes.
