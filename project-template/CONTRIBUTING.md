# Contribuir

Antes de abrir un Pull Request:

- Leé el README y revisá el estado del proyecto.
- Abrí un Issue para trabajo concreto o una Discussion para propuestas.
- Agregá o actualizá documentación cuando cambie el proyecto.
- Registrá la asistencia de IA y las decisiones humanas relevantes.
- No publiques secretos, datos personales, contratos ni datasets sensibles.
