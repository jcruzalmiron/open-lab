# Seguridad y datos sensibles

Este espacio es público por diseño, pero no todo material es publicable.

## Nunca publicar

- Tokens, contraseñas, claves API o archivos `.env`.
- DNI, domicilios, teléfonos, correos personales o datos de inscripción.
- Datasets con información identificable o sensible.
- Contratos, información privada de terceros o material sin autorización.
- Logs que incluyan credenciales o datos personales.

## Si encontrás un secreto

No lo copies en un Issue, Discussion o Pull Request. Avisá al equipo institucional por un canal privado, revocá la credencial si tenés autorización y documentá el incidente sin volver a exponer el valor.

Los workflows de los proyectos deben incluir un escaneo automatizado de secretos antes de publicar cambios.
