# Contribuir al Open Lab

La comunidad puede proponer ideas, reportar problemas, mejorar documentación y continuar proyectos existentes.

Las personas que se suman por primera vez pueden seguir la [guía de integración y colaboración del Open Lab](docs/guia-integracion-open-lab.md), que reúne el flujo, las reglas vigentes y las buenas prácticas.

## Antes de abrir un cambio

1. Revisá `README.md`, `AGENTS.md` y el estado actual del proyecto.
2. Para una propuesta nueva, usá Discussions o la plantilla de propuesta.
3. Para trabajo concreto, abrí un Issue describiendo el problema y el resultado esperado.
4. No subas secretos, credenciales, datos personales, contratos ni datasets sensibles.

Para los tres proyectos del primer EcoLab, seguí la [guía de colaboración y actualización de EcoLabs](docs/guia-aportes-ecolabs.md). Allí se indica dónde contribuir en cada nivel y qué documentación acompañar.

## Pull requests

- Explican qué cambia y por qué.
- Incluyen evidencia de pruebas o aclaran qué no pudo verificarse.
- Actualizan la documentación cuando cambia el comportamiento.
- Incluyen la trazabilidad de IA cuando se utilizó asistencia generativa.
- Se envían hacia el repositorio y la carpeta correctos; no se mezclan cambios del proyecto básico con los otros niveles.

## Trazabilidad de IA

Cada proyecto debe registrar qué partes fueron asistidas por IA, qué herramienta o modelo se utilizó, qué prompts fueron relevantes, qué decisiones tomó una persona y qué validaciones se realizaron. Ver `docs/trazabilidad-ia.md`.
